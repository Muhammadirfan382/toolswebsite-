## Join PDF files in a few taps

This tool combines several PDF documents into a single file. It is useful whenever a website, an office or a teacher asks for "one PDF": a job application with a CV, cover letter and certificates, a visa or university form with its supporting documents, a set of scanned receipts for an expense claim, or chapters of a report written by different people.

You can merge two files or many, change their order, and choose exactly which pages to keep from each one. The result is a normal PDF that opens in any reader.

## How it works

When you add files, the tool reads each one in your browser and shows a small preview of its first page and the number of pages it has. This makes it easy to check you picked the right documents before you start.

To change the order, drag a row up or down with a mouse, or use the arrow buttons, which also work with a keyboard and on touch screens. The file at the top of the list becomes the first part of the merged document.

Each file has a "Pages" box. Leave it empty to include the whole file. To keep only part of a document, type page numbers and ranges, such as `1-3, 5` or `4-` (page 4 to the end). If you type a page that does not exist, the tool tells you how many pages that file actually has.

When you press "Merge PDFs", the pages are copied into a new document one after another. When it is ready, you can download merged.pdf.

## Tips for a clean merged PDF

- **Check the order first.** The thumbnails show the first page of each file, which is usually enough to spot a mix-up.
- **Remove blank or duplicate pages** with the "Pages" box instead of editing the files beforehand.
- **Merging does not shrink files.** The merged PDF is roughly the size of all the parts added together. If a portal has an upload limit, run the result through [Compress PDF](/compress-pdf) afterwards.
- **Have photos instead of PDFs?** Turn them into a PDF first with [JPG to PDF](/jpg-to-pdf), then merge that file with the others.
- **Need a page as an image** for a presentation or a message? Use [PDF to JPG](/pdf-to-jpg) on the merged file.

## Password-protected and damaged files

Some PDFs are encrypted with a password. Their pages cannot be copied without it, so the tool shows a clear message for that file instead of failing silently. Open the document in a PDF reader, save a copy without the password, and add that copy instead.

If a file is damaged or is not really a PDF (for example a Word document renamed to .pdf), the tool says it could not be opened, so you know which file to replace.

## Your files stay private

Many online converters upload your documents to their servers. This one does not. The merging code runs inside your web browser, on your phone or computer, and your PDFs never leave your device. That matters when the documents include ID cards, bank statements, contracts or medical records.

There is no sign-up, no email address to give, and nothing is stored after you close the page.

## Works on iPhone, Android and PC

You do not need to install an app. The tool runs in any up-to-date browser:

- **On iPhone or iPad**, tap "Choose files" and pick PDFs from the Files app. After merging, the download is saved to Files, usually in Downloads.
- **On Android**, choose files from your downloads or storage, and find the merged file in your Downloads folder.
- **On a Windows PC or Mac**, you can also drag PDFs straight from a folder onto the drop area.

Because the work happens on your device, speed depends on the device. A handful of ordinary documents merges in moments. Very large scanned files take longer on older phones, and the tool warns you when a file is over 100 MB or has more than 300 pages.

## When to use a different tool

If you want a smaller file rather than a combined one, use [Compress PDF](/compress-pdf). If you only need to share one page, [PDF to JPG](/pdf-to-jpg) saves pages as images. For photos taken with your phone camera, [Compress Image](/compress-image) reduces their size before you add them to a document.
