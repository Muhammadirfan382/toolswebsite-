## Resize images the way you need

Different places need different image sizes. A social network may crop a picture that is the wrong shape, an application form may reject a photo that is too large, and a print shop needs a photo at the right physical size. This image resizer handles all of these in your browser.

## Four ways to resize

**Pixels.** Enter a width and height. With "Keep aspect ratio" on, you only need one of them; the other is calculated so the photo is not squashed. Turn it off to set both, for example a square 1080 × 1080.

**Percentage.** Make an image a set fraction of its current size, such as 50%. This is the quickest way to shrink large phone photos for email.

**Preset.** Pick a ready-made size for common uses, grouped into social media and documents. Presets set the dimensions for you and handle the cropping step.

**Print size.** Enter a width and height in centimeters, millimeters or inches, and a resolution (300 DPI by default). The tool calculates the pixels and records the resolution in JPG files, so the photo prints at the intended size.

Requirements differ between countries and change over time, so always follow the latest official notice. This tool helps you meet a size; it cannot check whether a photo meets rules about lighting, expression or background.

## Cropping without distortion

When the new size has a different shape from your photo, you choose what happens:

- **Crop to fill:** the photo fills the whole frame. Drag it (or use the arrow keys) to choose which part stays, and zoom with the slider or the + and − keys. This is best for profile pictures and ID photos.
- **Fit inside and add a background:** the whole photo stays visible, and the empty space is filled with a color you choose. Useful for product pictures and banners.
- **Stretch:** forces the exact size, which may distort the image. Use it only when that is acceptable.
