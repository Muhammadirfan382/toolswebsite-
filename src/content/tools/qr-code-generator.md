## Make a QR code in seconds

A QR code lets people open a link, join WiFi or save your contact details just by pointing their phone camera at it. This free QR code generator creates codes for nine kinds of content, lets you match colors to your brand and add a logo, and gives you high-resolution files to print or share. There is no sign-up and nothing to install.

## What you can put in a QR code

- **URL:** any web page, such as a restaurant menu, a Google Form, an online store, an Instagram profile or a YouTube channel. Type the address; https:// is added if you leave it out.
- **Text:** a short note, a code or instructions.
- **WiFi:** network name, password and security type, so guests can join without typing. Hidden networks are supported.
- **Email:** an address plus an optional subject and message, which open ready to send.
- **Phone:** a number that the phone offers to call.
- **SMS:** a number and optional message for a text.
- **WhatsApp:** a number and optional pre-filled message, using WhatsApp's official wa.me link format. Enter the number with its country code.
- **Contact (vCard):** name, phone, email, company, job title, website and address, which phones can save straight to contacts.
- **Location:** latitude and longitude that open in the phone's map app.

## Static codes: no expiry, no tracking

These are **static QR codes**. They never expire and have no scan limits, because the data is stored in the code itself. There is no redirect through this website, so we cannot see who scans your code, and your code keeps working even if this site changes or disappears.

The flip side is that a static code cannot be edited after printing. If you might change the destination later, point the code at a page you control, such as your own menu page, and update that page instead.

## Design options

**Size** sets the image from 256 to 2048 pixels. Larger images print more sharply.

**Colors** let you match your branding. Dark code on a light background scans most reliably. The generator warns you if the colors are too similar or if a light code sits on a dark background, since some scanner apps cannot read those.

**Margin** is the empty border around the code, measured in modules (the small squares). Scanners need a quiet border; four modules is the standard.

**Error correction** lets a code survive damage. Level L recovers about 7% of the code, M about 15%, Q about 25% and H about 30%. Higher levels make the pattern denser, so use H mainly when you add a logo.

**Logo.** Add a PNG, JPG, WebP or SVG image to the center. It is limited to 20% of the code's width, and error correction switches to H automatically.

## Test before you print

Scan your code with your own phone camera before printing, from the distance people will use. ## Downloads

Download a **PNG** for documents, slides and websites; an **SVG** for printing and design software, since it stays sharp at any size; or a **JPG** where other formats are not accepted. On supported browsers you can also copy the image straight to the clipboard.

## Private by design

The code is generated inside your browser. WiFi passwords, phone numbers and contact details are never sent to a server.
